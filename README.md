## 📂 Files in this Repository

| File | Description |
|------|-------------|
| `task1_basics.py` | Python basics — takes Name, College, Branch as input and displays formatted output |
| `task2_datatypes.py` | Declares Integer, Float, String, Boolean variables and prints their data types |
| `task3_operators.py` | Calculator performing Addition, Subtraction, Multiplication, Division, Modulus |
| `task4_conditionals.py` | Grade calculator using if-elif-else based on marks |
| `task5_loops.py` | For loop (1–20 & multiplication table) and while loop (even numbers 1–50) |
| `task6_functions.py` | User-defined functions — square of a number and average of three numbers |
| `task7_strings_collections.py` | String methods, List, Tuple, Dictionary, and Set operations |
| `task8_filehandling.py` | Creates a text file, writes to it, then reads and displays its content |
| `task9_student_management.py` | Mini project — Student Record Management System (Add/Display/Search/Delete) |
| `task1_output.png` ... `task9_output.png` | Terminal output screenshots for each respective task |

## ▶️ How to Run
Clone this repository and run any file individually:
```bash
git clone https://github.com/Gajanan-raje/Week-1-Python-Fundamentals-Assignment.git
cd Week-1-Python-Fundamentals-Assignment
python task1_basics.py
```
(Replace `task1_basics.py` with any other filename to run that task.)
